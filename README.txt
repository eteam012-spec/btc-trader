BTC Command Console V1
Desktop controller prototype for the BTC 15-minute simulation/paper workflow.

Includes:
- Manual and Auto modes
- Emergency stop
- Simulated UP/DOWN entry and SELL/EXIT
- Locked entry price
- Bankroll / max exposure / position controls
- Entry and exit timing signals
- Risk engine
- Assistance feed
- Responsive desktop/mobile layout

V1 intentionally does not place real orders or click external websites.
